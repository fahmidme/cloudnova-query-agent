# Original evaluation fixture

`invoices.csv` is an original 11-record fictional ledger authored for this project. It is not a subset of the supplied assessment data. Expected results were specified in `specs/EVALUATION.md` before implementation. `.example` email domains are intentionally non-deliverable.

Use the separately supplied assessment CSV with `python -m app ingest PATH --db work/cloudnova.sqlite`. The repository does not download source files or transmit them to a model.
